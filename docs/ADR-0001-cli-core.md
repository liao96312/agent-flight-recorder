# ADR-0001：CLI 内核与双宿主薄插件

- 状态：已接受
- 日期：2026-07-20

## 决策

`afr` CLI 是会话、进程、写盘前脱敏、规则、哈希链、制品、报告与验证的唯一实现。
Codex 和 Claude Code 插件只负责说明用法并以参数数组调用 CLI；插件不得复制证据逻辑。
v0.1 不接宿主 hooks。只有 wrapper 模式经真实使用证明不足时，v0.2 才增加 hook 解码器，最终事件仍由 CLI 排序和入链。

## 理由与边界

- CLI 可独立测试、发布和用于任意非交互命令行 Agent。
- 两个宿主共用同一行为，避免证据格式和安全策略分叉。
- wrapper 只能证明其进程输出和工作区前后状态；未接原生或 OS 证据时，隐藏工具、工作区外写入和网络均标记 `not_observable`。
- v0.1 哈希链用于发现未重算篡改，不对抗本机管理员，也不是数字签名。

完整的数据、状态、威胁、CLI 和退出码契约见 [PROJECT_PLAN.md](./PROJECT_PLAN.md#5-系统架构)。
